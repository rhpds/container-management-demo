# Module 01 — Console Overview

## Brief Overview

This chapter orients the audience to the OpenShift web console and establishes the foundation for all subsequent chapters. The presenter walks through the core navigation paradigms — Developer and Administrator perspectives — then highlights four high-value interface areas: the Main Dashboard for cluster-wide health, the Events page for real-time activity, the Software Catalog and Topology view for application visibility, and the embedded web terminal for in-browser CLI access. The chapter closes with a demonstration of user management and guided Quick Starts, showing how OpenShift reduces the barrier to entry for both new users and administrators.

## Audience and Time

- **Audience:** Sales engineers and technical presenters; technical audience watching the demo
- **Estimated duration:** ~45 min

## Learning Objectives

- Demonstrate how OpenShift Console perspectives (Developer and Administrator) serve different user roles without switching tools
- Explore the Main Dashboard, Events page, and Software Catalog to surface cluster and application health at a glance
- Demonstrate the embedded web terminal as a zero-install CLI entry point for cluster operations
- Demonstrate user management capabilities within the OpenShift Console
- Explore guided Quick Starts and explain how they accelerate day-one productivity for new users

## Key Takeaways

- OpenShift provides a unified, role-appropriate console experience that works out of the box — no additional tooling required
- The Software Catalog and Topology view give developers and operators immediate visibility into running workloads and their relationships
- The embedded web terminal eliminates the need to install `oc` or `kubectl` locally, reducing friction for on-site and remote demos
- User management is native to the console, making RBAC configuration accessible without deep CLI expertise
- Quick Starts lower the time-to-value for new OpenShift users by providing guided, in-product workflows
